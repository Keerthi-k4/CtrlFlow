# CtrlFlow

🚀 **CtrlFlow** is a real-time typing game website inspired by Monkeytype. Built using the MERN stack (MongoDB, Express.js, React, Node.js), it lets you test and improve your typing speed while tracking accuracy and WPM (words per minute).

---

## ✨ Features

- ⚡ **Real-time typing test**
- 📊 **Tracks WPM and accuracy**
- 🎮 **One engaging game mode**
- 🧑‍💻 **Interactive, clean UI**
- ☁️ **Persistent data with MongoDB**

---

## 💻 Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
